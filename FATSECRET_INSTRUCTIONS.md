# Інструкція: Реєстрація на FatSecret для API ключа

## Крок 1: Перейди на сайт
Відкрий браузер і перейди за посиланням:
**https://platform.fatsecret.com/register**

## Крок 2: Заповни форму реєстрації
- **Email**: введи свою електронну пошту (ту саму що для GitHub)
- **Password**: придумай пароль (мінімум 8 символів)
- **Confirm Password**: повтори пароль
- Постав галочку що погоджуєшся з умовами
- Натисни **"Create Account"**

## Крок 3: Підтверди пошту
- Перейди на свою пошту
- Знайди лист від FatSecret
- Натисни посилання для підтвердження

## Крок 4: Увійди в акаунт
- Перейди на **https://platform.fatsecret.com**
- Увійди зі своїми даними

## Крок 5: Отримай API ключі
- Після входу перейди в **"My Apps"** або **"Dashboard"**
- Натисни **"Create New App"** або **"Add Application"**
- Заповни:
  - **App Name**: "Sport Tracker"
  - **Description**: "Food recognition for sport tracking app"
- Натисни **"Create"**
- Ти побачиш:
  - **Client ID** (це як логін)
  - **Client Secret** (це як пароль)

## Крок 6: Скопіюй дані
Скопіюй ці дані і надішли мені:
1. **Client ID**: _______________
2. **Client Secret**: _______________

## Важливо!
- Client Secret показується лише один раз при створенні!
- Збережи його в безпечному місці
- Не ділись ним з ніким
